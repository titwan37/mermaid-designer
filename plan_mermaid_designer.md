# Mermaid Designer – Implementation Plan

## 🎯 Goal

Create a **stand‑alone** Mermaid live‑editor application in **`c:\Dev\mermaid-designer`**. The app will include a split‑pane editor, live preview with advanced front‑matter support, error handling, zoom/pan, export actions, theming, and template loading.

---

## 📁 Folder Structure

```
mermaid-designer/                # root of the project
├─ app/                         # Next.js App Router (TSX)
│   ├─ layout.tsx               # global layout + ThemeContext (dark/light)
│   ├─ page.tsx                 # entry point – renders <EditorPage/>
│   └─ editor/                  # core editor UI
│       ├─ EditorPage.tsx        # split‑pane, Monaco editor, ActionBar, TemplateSelect
│       ├─ MermaidViewer.tsx    # render SVG, zoom/pan, error overlay
│       ├─ utils/               # helper utilities
│       │   ├─ mermaidConfig.ts  # front‑matter parser
│       │   └─ errorBoundary.tsx # optional React error boundary
│       └─ components/           # UI pieces
│           ├─ ActionBar.tsx      # download/copy actions
│           └─ TemplateSelect.tsx # load bundled .mmd templates
├─ public/                      # static assets
│   └─ templates/                # optional .mmd template files
├─ tailwind.config.ts           # Tailwind config (darkMode: "class")
├─ globals.css                  # Tailwind imports + global styles
├─ next.config.mjs              # default Next.js config (optional customizations)
└─ package.json                 # scripts, dependencies, etc.
```

## 🧩 Core Components & Their Responsibilities

| Component | Responsibility |
|---|---|
| **layout.tsx** | Provides global dark/light mode via `ThemeContext` and loads Tailwind utilities. |
| **EditorPage.tsx** | Split‑pane layout, holds Monaco editor, passes code to preview, shows ActionBar & TemplateSelect, handles debounce. |
| **MermaidViewer.tsx** | Parses front‑matter, calls `mermaid.render`, displays SVG, adds zoom/pan (`react‑zoom‑pan‑pinch`), shows error overlay on parse failures. |
| **ActionBar.tsx** | Export `.mmd`, SVG, PNG (via `html2canvas`), copy code to clipboard. |
| **TemplateSelect.tsx** | Loads example `.mmd` files from `public/templates` and injects them into the editor. |
| **utils/mermaidConfig.ts** | Extracts YAML front‑matter (`--- … ---`) and returns `{ config, diagram }`. |
| **utils/errorBoundary.tsx** *(optional)* | Wraps `MermaidViewer` to prevent UI crashes in edge cases. |

## 🎨 Styling & UX Guidelines

- **Dark/Light toggle** updates both Monaco theme (`vs-dark` / `light`) **and** Mermaid theme (`dark` / `default`).
- Use Tailwind’s **glass‑morphism** utilities for the split‑pane background (`bg-white/70 dark:bg-gray-800/70 backdrop-blur`).
- Add subtle micro‑animations:
  - Fade‑in of the SVG (`transition-opacity`),
  - Hover scaling on ActionBar buttons (`hover:scale-105`).
- Keep the UI responsive: on screens < 640 px stack panes vertically.
